# `.claude/rules/` — 実装品質ルールの分離先

CLAUDE.md が肥大化（200 行超）しないように、再発防止ルールや
ドメイン固有の実装規約はこのディレクトリに `*.md` で分離し、
CLAUDE.md からは `@.claude/rules/xxx.md` で参照する。

## 使い方

1. ルールファイルを追加する（例: `p0-bug-patterns.md`）
2. CLAUDE.md の該当セクションに参照を追記する:

   ```md
   詳細な再発防止パターン: @.claude/rules/p0-bug-patterns.md
   ```

## 想定する用途（例）

| ファイル | 内容 |
|---|---|
| `p0-bug-patterns.md` | TDD をすり抜けた P0 バグの再発防止パターン（レビューで見つかった実例ベース） |
| `<domain>-rules.md` | ドメイン固有の絶対ルール（データ整合・命名規約など） |

> このディレクトリの中身はプロジェクト固有になる。テンプレートには
> この README のみを置き、実際のルールは各プロジェクトで追記すること。
